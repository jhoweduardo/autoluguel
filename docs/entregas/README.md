# Entregas finais

Cada tarefa consolidada tem um registro `<ID>.md` nesta pasta. O registro reúne o que foi entregue, os critérios de aceite, as evidências do QA, a versão validada e os limites da entrega.

O coordenador aciona `closeout` somente após o parecer independente `APROVADO` e a conclusão formal para a mesma versão. Se faltar evidência, os documentos da tarefa permanecem nas pastas de origem e o coordenador recebe as lacunas. O agente preserva documentos compartilhados e só remove transitórios exclusivos, enumerados, recuperáveis e com autorização aplicável.

Consulte o [backlog](../backlog.md) para o estado de cada história, o [fluxo da equipe](../agentes/fluxo-de-trabalho.md) para a sequência e o [modelo de entrega final](../agentes/templates/entrega-final.md) para o conteúdo do registro.
