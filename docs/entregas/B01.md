## Reprodução e limites

O [guia de CI](../ci.md) reúne a instalação, os builds, o restore bloqueado e o validador OpenAPI. Após preparar .NET 10, Node 24 no PATH (inclusive para o Vite), Chromium do Playwright, Docker e a imagem `postgres:17-alpine`, execute a partir da raiz:

```powershell
node tests/ci/run-suite.mjs unit
node tests/ci/run-suite.mjs web
node --test tests/ci/gates.spec.mjs
node tests/ci/readiness.mjs
```

A suíte negativa local terminou com quatro aprovados, sem falhas/ignorados, código 0. O resultado hospedado positivo está comprovado em nível de execução; a consulta secundária de jobs retornou HTTP 502 e os detalhes dos jobs vêm da captura, sem contagens ou logs hospedados inferidos. Não houve execução verde nova após a prova negativa, pois a asserção ficou isolada da versão íntegra. O cancelamento foi comprovado localmente, não no GitHub. Não foi executado `actionlint`; a evidência de funcionamento são os dois resultados no próprio provedor. O encerramento documental não repetiu testes nem alterou aplicação, workflow ou harness.
